# 卡牌概念圖來源

此目錄保存已確認可查看的視覺**概念稿**，不是正式卡牌資料或可直接供紙娃娃使用的透明拆分素材。

- `ingredients-base-01.png`：3×3 圖表，依序為紅茶、綠茶、牛奶／奶精、珍珠、仙草／布丁、紅豆、椰果。
- `ingredients-toppings-02.png`：補充圖表，包含白玉珍珠、波霸、綠豆、粉粿、花生。
- `card-back-*.png`：一般藍、黑金、紫金、紅金卡背預覽；稀有度規則尚未定案。

互動預覽在 `client/public/previews/`，目前透過圖表定位顯示卡面。正式卡片若需獨立圖檔或 atlas，應先建立卡片 ID 與圖像座標的對照表，再由美術與資料部門共同確認。
