# 戰鬥紙娃娃與手持飲料：首版企劃規格

狀態：**供本機單人 Web 原型實作的視覺規格**（2026-10-05）；不修改射擊傷害、伺服器配方或戰鬥判定。依據[合成規則](synthesis_rules.md)與[單機對戰規格](solo_web_vertical_slice.md)：戰前製作並裝備、原料永久解鎖，戰鬥可切換最多兩種配料彈藥。

## 現況與本次目標

整備畫面已有 `DrinkCup`，用透明杯殼圖、液色與配料透明素材疊成飲料；戰鬥畫面目前用四角色圖表、程式繪製手臂和吸管，尚未把**已裝備飲料**畫在角色手中。`PaperDollRenderer.tsx` 仍是占位檔。這次只需讓四名角色都能拿著與各自配方一致的小杯，讓玩家在移動、射擊、切換配料時辨認其飲料。先沿用現有透明杯與配料素材，無須重畫整個角色或場景。

## 唯一資料來源與視覺映射

對戰角色以伺服器傳來的 `BattlePlayer.drink = {baseId, dairyId, toppingIds}`、`slot`、`facing`、`angle`、`moving`、`alive` 為準。`toppingIds` 是依配方順序的 1～2 種，`slot` 是當前吸管彈藥位置；渲染器不得依玩家本地整備暫選、抽卡動畫或圖片顏色推測內容。飲料外觀不影響碰撞盒、投射物傷害、射速或縮圈。

| 欄位／值 | 戰鬥中手持杯可見變化 |
| --- | --- |
| `baseId = red_tea` | 紅茶基底透亮琥珀棕；無乳品時液色約 `#934517` |
| `baseId = green_tea` | 綠茶基底透明黃綠；無乳品時液色約 `#6c8425` |
| `dairyId = null` | 保留茶色與少量透光，不加白色混合紋 |
| `dairyId = milk` | 液色變柔和：紅茶約 `#b77540`、綠茶約 `#95a76a`；加一道淡乳白混合紋 |
| `dairyId = creamer` | 比牛奶略暖、略厚：紅茶約 `#c19461`、綠茶約 `#adb072`；加淡金奶霧紋。首版只區分外觀，不增加屬性 |
| `toppingIds[0..1]` | 在杯底顯示各原料對應透明素材；只有一種料就鋪滿底部，兩種料各佔約一半且互相交錯 |
| `slot = 0/1` | 高亮目前彈藥的杯內小簇、HUD 配料圖示與吸管出口閃色；杯內配料總量與位置不因切換而重排 |

配料 ID 必須與既有資料一致；映射沿用 `CardArt.tsx` 的 `toppingSprites`：`pearl` 黑珍珠、`white_pearl` 白玉、`boba` 波霸、`grass_jelly` 仙草方塊、`pudding` 完整單顆布丁、`red_bean` 紅豆、`coconut_jelly` 椰果方塊、`mung_bean` 綠豆、`yellow_jelly` 粉粿方塊、`peanut` 花生。素材位於 `client/public/assets/avatar/toppings/`。未知 ID 不應被畫成其他已解鎖原料；顯示通用中性色佔位並記錄錯誤。布丁只呈現一顆縮小的完整布丁，不複製成規則排列的方塊。

## 圖層、位置與動作

以角色地面座標為錨點；目前戰鬥角色繪於本地 `(-30,-68)`、尺寸 `60×84`。小杯在面向右時放角色前方、靠手的位置，建議可視寬 **18～22**、高 **27～32** 遊戲單位；面向左時水平鏡像，不能壓住臉或 HP 條。移動時杯、手、吸管跟角色輕微起伏，死亡後杯與角色一起失去互動亮光。這些是畫面尺寸，不改伺服器角色半徑 15 或既有投射物起點。

畫法由後往前固定如下：

1. 地面影與角色本體圖表。現有本體已含手臂，首版可在其上畫持杯前臂，不要求拆出新手臂圖。
2. 杯內液色：以杯型透明區裁切，保留透光與杯底較深色；乳品混合紋在液色上。
3. 杯底配料：貼近杯內下緣，兩層不規則沉底、大小和角度略不同，不漂在上層。小尺寸時每種料以少量清楚的簇表示，不能把素材排成等距格子；布丁仍為一顆。
4. 透明杯殼、杯口和金屬邊：可縮用 `cup-shell-gold-v1.png`，裁切與液體完全對齊；配料不可蓋在杯殼外。
5. 前手掌／手指壓在杯殼前緣，明確表現「拿著杯子」。角色左右翻轉時手與杯一起翻轉。
6. 吸管在臉／手前，出口始終指向 `angle`；發射亮光與彈體從既有 `arena.projectileOrigin` 錨點出現。杯是手持物，不能為追逐準星而移到吸管出口；吸管可獨立旋轉。

杯子與吸管的特效不能遮住鄰近角色、縮圈邊界或主要命中數字。四人同畫面縮小時，仍至少能分辨紅／綠茶和深／淺配料；更細的料名由 HUD 補充。

## 切換與發射的視覺反饋

- 當伺服器回傳的 `slot` 改變，於 **0.15～0.25 秒**內給杯口一次短光圈、被選中配料小簇脈衝，HUD 的 A／B 圖示與名稱同步高亮。可從杯內有一顆／一小塊配料向吸管移動，但只是視覺演出，不扣除杯內配料。
- 只有一種配料時，不顯示可切換提示；重複點擊不能製造亮光或重置射擊冷卻。
- 射擊的出口閃光與飛行彈體使用當次 `shoot` 事件／`projectile.toppingId` 的顏色、輪廓。切換後舊彈體保持原配料外觀；不可依最新 `slot` 把空中彈體變色。
- 普通珍珠、白玉、波霸應呈圓潤真實顆粒；仙草、椰果、粉粿保持方形切面。命中特效可以放大一瞬，但不能假裝改變實際命中半徑。
- 首版紙娃娃不因稀有度加戰力光環；稀有度仍未定稿。

## 驗收條件與後續擴充

1. 製作並裝備「紅茶＋牛奶＋珍珠＋波霸」，進場杯內可見奶茶色及兩種沉底配料；切換時杯內僅高亮對應料，射出彈體與 HUD 一致。
2. 改裝「綠茶＋不加乳品＋仙草」，重新進場呈綠茶色、方形仙草；僅一種彈藥不能切槽。再驗證奶精與牛奶不是完全相同色／紋。
3. 四名角色各讀自己的 `drink`；不能把玩家飲料套到電腦身上。左右面向、移動與射擊時杯與手保持黏合，飲料不漂浮、液體和配料不溢出杯外，彈體從吸管出口出現。
4. 桌面和手機橫向可辨認杯與目前彈藥；切換與射擊特效沒有造成畫面裁切或明顯掉幀。素材未載入時有簡潔回退，不阻塞對戰。

後續可擴充真正拆分的角色手臂圖、不同杯型／吸管皮膚、料在杯中受移動慣性輕微晃動、茶底和乳品技能；都應以版本化外觀資料新增，不把美術資產路徑或戰力邏輯寫死在畫面判定裡。首版只需一款杯殼與現有十種配料素材。
