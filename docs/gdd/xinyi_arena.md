# 信義街區・本機可玩場地

董事長已確認以台北信義區街景取代沙漠。本機試玩使用獨立空街景底圖 `client/public/assets/backgrounds/taipei-xinyi-arena-v1.png`，101 是遠景地標；4 位角色使用透明圖層 `client/public/assets/characters/boba-fighters-v1.png`，由 Canvas 依伺服器座標即時繪製。人物、子彈、HP、警戒圈不是背景圖片的一部分。原先批准的美術預覽保存在 `client/public/assets/backgrounds/concepts/taipei-xinyi-arena-preview-v1.png`。

場地邏輯座標 900×520，建築、花台與街角設有伺服器碰撞矩形。手機橫向採等比例鏡頭追蹤玩家；開場鏡頭先展示 101，再平滑轉為跟隨。螢幕寬高比不改變命中判定。

騎樓暗巷與街角巷道是可走入的隱蔽區。站在區外的玩家收不到區內存活對手的座標，區內玩家可看見同一區內的對手；雙方投射物在隱蔽區邊界消失，避免從看不到的巷內射擊街外。伺服器 AI 也遵守同一可見性，失去目標後往巷口巡邏。完整戰鬥紀錄在結算後顯示。

本機試玩的玩家攻擊採伺服器自動鎖定：從存活且可見、直線未被遮蔽物擋住的對手中選最近者；沒有合適目標時按發射不會產生彈丸。客戶端送來的瞄準方向與目標 ID 不影響判定。角色面向隨鎖定方向左右翻面，吸管根部接在嘴邊，彈丸從同一根吸管的管口射出。彈道碰撞以地面邏輯座標計算，畫面把彈丸提升至嘴巴高度，避免視覺高度改變街道遮蔽判定。

這是單機玩法驗證，地圖美術與碰撞仍是第一版近似對位。之後應把建築遮罩、巷道入口與動態紙娃娃杯層拆成正式素材與資料，再做真人多人同步及手機 Safari 實機測試。
