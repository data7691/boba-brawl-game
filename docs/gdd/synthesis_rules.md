# 飲料合成規則草案

狀態：**概念預覽紀錄，正式規則待確認**（2026-10-04）。

## 已確認

- 玩家在獨立整備畫面戰前使用已解鎖的原料卡合成飲料並裝備；進場時人物持杯與吸管、紙娃娃外觀隨飲料變化。
- 原料卡是永久解鎖，製作不消耗。兩種配料可在戰鬥中切換作為吸管發射的彈藥。卡片稀有度與重複抽到的卡如何處理稍後調整。

## 現有預覽的暫定輸入

| 類別 | 可選數 | 已展示原料 |
| --- | --- | --- |
| 茶底 | 必選 1 | 紅茶、綠茶 |
| 乳品 | 0～1 | 牛奶、奶精 |
| 配料 | 0～2 種 | 珍珠、仙草、布丁、紅豆、椰果、白玉珍珠、波霸、綠豆、粉粿、花生 |

預覽會依組合改變杯中色澤、配料圖案與飲料名稱，例如「紅茶＋牛奶＋珍珠 → 珍珠鮮奶茶」。這是前端展示規則，不會扣卡、解鎖、保存或影響戰鬥；正式流程將由伺服器核准解鎖、製作、裝備和彈藥切換。

## 正式設計待補

1. 配方是否允許沒有茶底、同種配料重複及超過兩種配料？
2. 已解鎖的原料可反覆製作；仍須定義成品保存上限與重複抽到卡的處理。
3. 飲料成品如何命名、儲存、裝備及拆解？同配方可否持有多杯？
4. 哪些飲料屬性影響外觀，哪些影響技能與數值？需有上限和平衡規則。
5. 伺服器需按配方版本與玩家已解鎖的原料驗證；製作與裝備變更須可靠保存，不能由前端自行認定。
