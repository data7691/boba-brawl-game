# 單機 Web 大亂鬥：首個可玩縱切企劃

狀態：**供本次原型實作及試玩調整的企劃參數**（2026-10-05），不是正式平衡定稿，也不代表真人多人連線或正式經濟系統已完成。既有[玩法草案](realtime_brawl_concept.md)中的長期方向仍有效。

## 本次試玩要驗證什麼

玩家在整備畫面選 1 種茶底、0～1 種乳品、1～2 種已解鎖配料，製成飲料並裝備；人物持杯與吸管進入沙漠場景。單機 Web 建立 **1 玩家＋3 電腦**的 4 人混戰，玩家可移動、瞄準、射擊、切換兩種配料彈藥。HP 歸零淘汰且不重生，剩下最後 1 人即結算，可一鍵重賽。此版由**本機 Node HTTP 服務持有並驗證戰鬥狀態**，瀏覽器只送操作指令；尚未提供多名真人加入同一房間的連線功能。

測試用原料解鎖可保留既有抽卡／合成預覽的視覺流程；原料卡一經獲得永久可用，合成不扣卡。為保證首次進場，新訪客預設解鎖紅茶、牛奶、珍珠、波霸；其餘原料可用免費測試抽卡取得，**不設定正式機率**。訪客原料解鎖、重複數、成品與裝備由本機服務驗證並持久化。現有 14 種原料為紅茶、綠茶、牛奶、奶精及 10 種配料；20 張卡與稀有度後續另行設計。

## 操作與回饋

| 動作 | 手機橫向 | 桌面測試 |
| --- | --- | --- |
| 移動 | 左下虛擬搖桿，容許 360° 方向 | WASD／方向鍵 |
| 瞄準射擊 | 右側按住拖曳瞄準並連發，鬆開停止；顯示方向線 | 滑鼠指向、按住連發 |
| 切換配料 | 右側清晰標示 A／B 的切換鍵；僅 1 種料時停用 | Q |

HUD 必須顯示當前配料名稱／圖像、另一配料、共用射擊冷卻、HP、存活人數與縮圈倒數。吸管口是投射物發射起點；命中時有短音效、受擊閃光與浮動傷害數字，死亡時顯示名次。切換配料立即生效，不改變已在飛行的彈體，也不重置射擊冷卻。觸控按鈕與搖桿避開 iPhone Safe Area；不要要求玩家在戰鬥中翻卡或開背包。

## 沙漠場景與縮圈

場景有沙地與 5 個實心岩石／茶攤廢墟掩體；岩石阻擋角色與子彈，外觀可簡化但碰撞邊界須看得出來。四角出生與中心有可行走通道。首版不做傳送門或高低差。

安全區以場景中心 (450,260) 為圓心，初始半徑 560 單位。開局 **30 秒**後，用 90 秒線性縮至半徑 100；圈外每 **0.5 秒扣 7 HP**（約 14 HP／秒）。縮圈有邊界光效、倒數與音效提示；玩家與電腦同受此規則。120 秒後維持最小圈直到結算；180 秒的時限確保可完整玩完。

## 電腦行為（3 名，能完成一局）

電腦每個戰鬥更新步驟選最近的存活對手；距對手超過 170 單位則靠近，低於 100 單位則後退，其餘時間橫向走位。若距圈心超出安全半徑 35 單位內，優先往中心移動。距離目標 470 單位內則嘗試射擊，瞄準有少量誤差；共用冷卻仍限制發射頻率。若已裝備兩種配料，約每 7 秒切換一次。三名電腦分別使用不同外觀／飲料組合，並可用名稱辨認。

電腦遵守與玩家相同的移動速度、射擊冷卻、碰撞、HP 和安全區傷害。開發時可顯示或記錄「目前目標、狀態、上次射擊」來排查卡住與不開火，正式畫面不顯示這些除錯資料。

## 本次可驗收的完整循環

1. 從試玩入口進入整備，至少可製作「紅茶＋珍珠」並裝備；選兩種配料時畫面能顯示兩槽。
2. 進入 4 人沙漠對局，開場倒數後玩家和 3 名電腦都能移動、射擊、扣血；兩槽能切換，子彈外觀吻合配料。
3. 遮擋、命中、淘汰、縮圈與勝負能在單次對局中走完；無法躲到場外或無限拖局。
4. 結算顯示名次、擊倒數、造成傷害與勝負，能重賽或回整備。
5. 手機橫向與桌面瀏覽器可操作，畫面無左右裁切；音效在首次觸控後可播放，並有靜音鍵。

訪客收藏、抽卡、合成與裝備以本機服務的持久化資料為準；瀏覽器不得自行宣稱已解鎖、製作成功、造成傷害或獲勝。本次本機服務可驗證試玩操作，但還不是正式部署的多人房間或生產級帳號儲存。此份企劃只界定第一個可玩的單機 Web 原型，高樓與海底、真人連線、PVP 排位、商城和正式抽卡機率不在本次驗收內。
